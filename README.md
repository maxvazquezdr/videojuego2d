# 👻 Cacería Espectral - Examen de Graficación

Videojuego 2D desarrollado en HTML5 Canvas y JavaScript para la materia de Graficación, con una temática centrada en Día de Muertos / Halloween.

## 🚀 Características y Requisitos Técnicos
* **Gráficos 2D:** Renderizado procedural y optimizado mediante HTML5 Canvas con transparencias reales.
* **Entidades Activas:** Mantiene exactamente 25 objetos (fantasmas) simultáneos en pantalla con reaparición automática al ser eliminados.
* **Patrones de Movimiento:** Implementación de 4 comportamientos dinámicos distintos (vertical hacia arriba, vertical hacia abajo, desplazamiento diagonal y trayectoria circular).
* **Física de Colisiones:** Detección de colisiones circulares entre objetos con rebote físico y efecto visual de resplandor.
* **Interfaz de Usuario:** Maquetado con Bootstrap 5, barra de navegación, tarjeta de instrucciones, contador en tiempo real y controles de audio.
* **Puntero Personalizado:** Indicador interactivo temático de Halloween integrado por CSS.

## 🛠️ Tecnologías Utilizadas
* **HTML5 Canvas** (Gráficos y animaciones 2D)
* **JavaScript (ES6)** (Lógica de juego, físicas y colisiones)
* **Bootstrap 5** (Estilos y diseño responsivo)
